# Signaler une faille de sécurité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilise le signalement privé de GitHub : onglet **Security** du dépôt → **Report a vulnerability**. Décris la faille, comment la reproduire et la version concernée (visible dans **À propos**).

Seule la dernière version publiée reçoit des correctifs de sécurité.
